О проекте

AutoDev Sandbox — песочница для сквозной проверки AutoDev: задачи с телефона превращаются в изменения кода, которые автоматически собираются и выкладываются на GitHub Pages.

Сейчас здесь простой калькулятор (сложение и умножение) на чистом JavaScript без сборки и зависимостей.
